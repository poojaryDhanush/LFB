# Line Follower Robot Workshop – Nitte Robotics Club

## Overview
Participated in a hands-on Line Follower Robot workshop conducted by the Nitte Robotics Club, where we designed, built, and tested a fully functional robot from scratch. This project provided practical exposure to robotics hardware, embedded systems, and real-time debugging.

---

## Key Activities & Contributions

### Sensor & Circuit Understanding
Learned how IR sensors operate and how the complete circuit logic is structured for line tracking.

### Bot Base Fabrication
Observed and understood the laser-cutting process used to design and manufacture the robot chassis.

### Hardware Assembly
Placed components on a zero PCB and performed precision hand-soldering for all electrical connections.

### Coding & Calibration
Uploaded embedded code and fine-tuned sensor threshold values for accurate and stable line tracking.

### Testing & Debugging
Conducted repeated test runs, diagnosed hardware/software issues, and implemented real-time fixes.

### Team Collaboration
Worked collaboratively with Ashlesh Y Saliyan and Charith to divide responsibilities and solve technical challenges.
